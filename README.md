## Ejecutar el portfolio en local

El sitio es estático y no necesita instalar paquetes. Desde la raíz del repositorio, inicia un servidor local sencillo:

```bash
python -m http.server 8000 --directory web
```

Después abre [http://localhost:8000](http://localhost:8000). También puedes abrir `web/index.html` directamente en el navegador.
